
ระบบคิดยอดตัวเลข + คีย์เข้าระบบ + Discord Bot (รันไฟล์เดียว)
=============================================================

ไฟล์ที่ต้องวางไว้ในโฟลเดอร์เดียวกัน:
  server.py       ← รันไฟล์นี้ไฟล์เดียว (มีทั้งเว็บเซิร์ฟเวอร์ + บอท Discord + เมนูจัดการคีย์)
  index.html      ← หน้าบันทึกเลข (ต้องใส่คีย์ถึงจะเข้าได้)
  app.js
  admin.html      ← หน้าแดชบอร์ด / ระบบหลังบ้าน (ต้องใส่คีย์เหมือนกัน)
  admin.js
  style.css
  config.json     ← สร้างอัตโนมัติครั้งแรก แล้วมาใส่ Discord Token (หรือคัดลอกจาก config.example.json)

วิธีรัน (Termux / Windows / Mac / Linux):
  pip install discord.py        # ติดตั้งแค่ครั้งเดียว (ถ้าจะใช้บอท)
  python server.py              # รันโปรแกรม → เว็บเซิร์ฟเวอร์เปิดอัตโนมัติทันที
                                #   เปิด http://<IP>:8000 ได้เลย ไม่ต้องเข้าเมนู 03

เมนูหลัก:
  03. Start Local Server   → เปิดเว็บ http://<IP>:8000
  04. + Public Tunnel      → เปิด URL สาธารณะผ่าน cloudflared (ต้องมีไฟล์ cloudflared)
  06. Key Manager          → ดู/สร้าง/ลบคีย์
       - สร้างคีย์: ตั้งชื่อคีย์เองได้ (1-100 ตัว A-Z 0-9) หรือกด Enter = สุ่ม 4 ตัว
         แล้วระบุจำนวนชั่วโมง 1-inf  (>= 10000 ชั่วโมง = ถาวร ไม่หมดอายุ)
         และใส่ชื่อเจ้าของ/หมายเหตุได้
       - ทุกคีย์แสดงวันหมดอายุเสมอ
  07. Discord Bot Setup    → ใส่ Bot Token / Guild ID
  08. ดู Log               → ประวัติการใช้งานทั้งหมด (log ไม่ขึ้นจอหลัก ดูได้ที่เมนูนี้เท่านั้น)

ระบบคีย์:
  - คีย์รูปแบบ XXXX-XXXX-XXXX (พิมพ์มี/ไม่มีขีดก็ได้)
  - บอท Discord พิมพ์ /getkey → ได้คีย์ส่วนตัว ใช้ได้ 24 ชั่วโมง (1 คน 1 คีย์ ถ้ายังไม่หมดจะได้คีย์เดิม)
  - สร้างใน Termux (เมนู 06) → ระบุชั่วโมงได้เอง, >=10000 = ถาวร
  - เซิร์ฟเวอร์ตรวจคีย์ทุกครั้งที่เรียก /api/data (คนนอกไม่สามารถโหลด/บันทึกข้อมูลได้ถ้าไม่มีคีย์)
  - หน้าเว็บจำคีย์ไว้ในเครื่อง (ติ๊ก "จำคีย์นี้ไว้") ไม่ต้องใส่ซ้ำทุกครั้ง
  - เซิร์ฟเวอร์เปิดให้ดาวน์โหลดเฉพาะไฟล์หน้าเว็บ; config, keys, logs และ backup ไม่ถูกเสิร์ฟเป็นไฟล์
  - API รับ JSON ได้สูงสุด 32 MB และตรวจสอบโครงสร้างก่อนบันทึก

ตั้งค่า Discord Bot:
  1. ไป https://discord.com/developers/applications → New Application
  2. แท็บ Bot → Reset Token → คัดลอก Token มาวางใน config.json (หรือเมนู 07)
  3. แท็บ OAuth2 → URL Generator → เลือก scope: bot + applications.commands
     → เลือก Permission: Send Messages, Use Slash Commands → เปิดลิงก์เพื่อเชิญบอทเข้าเซิร์ฟเวอร์
  4. (แนะนำ) ใส่ Guild ID ใน config.json ด้วย → คำสั่ง /getkey จะขึ้นทันที ไม่ต้องรอ global sync
  5. รัน python server.py ใหม่ → บอทจะออนไลน์เอง พิมพ์ /getkey ใน Discord

หน้าแดชบอร์ด: เข้าที่ http://<IP>:8000/admin.html (ต้องใส่คีย์ก่อน)
  - ดูจำนวนงวด, คีย์ที่ใช้งานได้, เวลาเซิร์ฟเวอร์
  - ตารางสรุปยอดรวมแต่ละงวด กดที่แถวเพื่อดูรายละเอียดเลขแต่ละตัว
